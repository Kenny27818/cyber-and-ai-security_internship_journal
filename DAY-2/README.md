Today's topic was about the fundamental concepts in cybersecurity and networking.

-> CIA Triad
  It represents the three semgments which are crucial for the security of any system 
    -> Confidentiality
    -> Integrity
    -> Availability

-> Cyber-Killchain
  Founded by Martin Lockheed, is a cybersecurity framework that maps the stages of a cyber attack.
  It is comprised of 7 layers:
    -> Reconnaissance
    -> Weaponisation
    -> Delivery
    -> Exploitation
    -> Installation
    -> Command & control
    -> Action on objectives

-> Studied about security policieswe should be aware of when entering MNCs, MAANGs

-> Networks
  Learnt about the different kinds of networks used for various applications and ranges,
  Types of topolgies:
  -> Bus topology
  -> Star topology
  -> Ring topology
  -> Mesh topology
  -> Hybrid

  Networking devices which we use:
  -> Hub - sends the same data to all
  -> Switch - only to intended recipient
  -> Router - connect to different network
  -> Firewall - moniters and controls traffic
  -> Network Interface Card (NIC) - allows a device to connect to a network
  -> Load Balancer - distributes incoming network requests
  -> Wireless Router (in-built) - distributes internet connection and manages network traffic

  IP Addresses - Public & Private
  -> ipv4 - 32 bit address
  -> ipv6 - 128 bit address

  public - unique & accessible to everyone
  private - only accessed by select members

These topics gave me a deeper insight into the defensive and offensive stages of cybersecurity, helped me gain an in-depth understanding of how networks work.
